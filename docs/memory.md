## Gotchas

- **CSS modules need the Tailwind loader scoped.** create-next-app 16.4 adds a Turbopack rule `"*.css": { loaders: ["@tailwindcss/turbopack"], as: "*.css" }`. It also matches `*.module.css` and turns modules into plain CSS, so every `styles.x` is `undefined` and the page renders unstyled. `next.config.ts` now adds `condition: { not: { path: /\.module\.css$/ } }`.
- **Screenshots: never use `captureBeyondViewport`.** It collapses type sized in `vw` (the hero h1 vanished). Capture real viewports and scroll to sections; the scratchpad script `cdp-shots.mjs` does this with reduced motion so the score ring is fully drawn.
- **The tasteskill inspector counts hidden text.** Its line counter walks every text node in an element, including content clipped in a collapsed grid row, so a collapsed command row "wrapped to 3 lines". Render collapsed content conditionally instead of hiding it.
- **tasteskill lives outside the repo.** Cloned to the session scratchpad from github.com/Leonxlnx/taste-skill. Gate: `node <skill>/scripts/lint.mjs <files>` and `node <skill>/scripts/inspect.mjs <url> [--app]` on the production build. The dealt sheets are kept in `.taste-skill/direction.json` and `.taste-skill/app/direction.json`; screenshots there are git-ignored.

- **npm on this machine is slow.** The `next` tarball took about 41 minutes to download and 30 to unpack on D:. It's now in the npm cache, so use `npm install --prefer-offline`. Run npm from PowerShell, not Git Bash.
- **vitest 5 needs `@types/node` 22 or later.** create-next-app pins `^20`, which makes npm fail with ERESOLVE.
- **Preview tool reads the workspace launch.json** (`D:\Downloads\MATITHI\.claude\launch.json`, which starts the TATVA app on port 3000). For this project, run `npx next dev -p 3217` from PowerShell and open the URL directly.
- **Port map:** 3217 this project, 3210 trip-splitter, 3100 TATVA V3, 3000 workspace tatva-dev.
- **Headless screenshots:** Edge's `--window-size` has a minimum width, so phone shots come out cropped. Use DevTools-protocol device emulation for true 390px captures. An iframe wrapper from `file://` didn't hydrate reliably.
- **PowerShell here-strings don't pipe into `git commit -F -`.** Write the message to a file and use `-F <file>`.
- **`gh auth login` "Hostname" prompt** only appears if you pick "Other" (GitHub Enterprise). Pick GitHub.com.
- **Robots.txt can differ by visitor.** Some sites serve different rules or block unknown agents; the tool reports what it was served.
