## Gotchas

- **npm on this machine is slow.** The `next` tarball took about 41 minutes to download and 30 to unpack on D:. It's now in the npm cache, so use `npm install --prefer-offline`. Run npm from PowerShell, not Git Bash.
- **vitest 5 needs `@types/node` 22 or later.** create-next-app pins `^20`, which makes npm fail with ERESOLVE.
- **Preview tool reads the workspace launch.json** (`D:\Downloads\MATITHI\.claude\launch.json`, which starts the TATVA app on port 3000). For this project, run `npx next dev -p 3217` from PowerShell and open the URL directly.
- **Port map:** 3217 this project, 3210 trip-splitter, 3100 TATVA V3, 3000 workspace tatva-dev.
- **Headless screenshots:** Edge's `--window-size` has a minimum width, so phone shots come out cropped. Use DevTools-protocol device emulation for true 390px captures. An iframe wrapper from `file://` didn't hydrate reliably.
- **PowerShell here-strings don't pipe into `git commit -F -`.** Write the message to a file and use `-F <file>`.
- **`gh auth login` "Hostname" prompt** only appears if you pick "Other" (GitHub Enterprise). Pick GitHub.com.
- **Robots.txt can differ by visitor.** Some sites serve different rules or block unknown agents; the tool reports what it was served.
